### What was built and why

The home is a registry-owned institutional page, not an archive record. English
is authored directly in HTML for a complete no-JavaScript baseline. The shared
widget adds only the accepted page-owned theme behavior and the bounded loader
path later locales can activate. It does not contain support routes, payment
state, or hidden JA/ZH options.

The home makes Vextreme's institutional purpose, four equal alignments, project
lineage, archive, and Terrain entry points public. Support and VexLife remain
honest pending cards rather than dead or private links. The root archive page
and sitemap derive the active home from the lifecycle registry, while the
reserved support identity remains undiscoverable.

Evidence is written from the registry's one authored matrix as
`{slug}-{locale}-{theme}-{viewport}.png`. The harness drives the real theme
control, checks markers and locale state, rejects runtime errors and horizontal
overflow, verifies local links and first-Tab skip navigation, and renders with
the declared system-font fallbacks when third-party fonts are unavailable.

  grouped it under `common` and correctly withheld the required bundle. Added
  explicit `scope: institution` and `category: system` before accepting any
  projection.
- Playwright was installed without a default browser, and the first launch
  failure left the harness's local server open. Moved browser launch inside the
  cleanup boundary and used a temporary npm-delivered Chromium executable for
  local evidence without changing repository dependencies.

  fallback. Added a narrow-screen type boundary and kept overflow as a blocking
  browser assertion.

  grid. Visual inspection changed that component to an intentional 2×2 desktop

  bump was not idempotent: `2.1.0 → 2.2.0 → 2.3.0`. The prior repair had proved
  only the no-bump path. The target now derives from the last committed bump's
